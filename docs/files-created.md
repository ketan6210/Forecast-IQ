## Local generated artifacts

The following were also created for execution and are intentionally ignored by `.gitignore`:

- `.env`: local development settings, including ports 8010/5180; no external secrets.
- `.venv/`: Python environment and installed dependencies.
- `storage/`: local SQLite fallback and generated runtime files.
- `frontend/node_modules/`: installed JavaScript dependencies.
- `frontend/dist/`: compiled frontend assets.
- `frontend/tsconfig.tsbuildinfo`: TypeScript build cache.
- `frontend/test-results/`: browser-test artifacts.
- Python bytecode, pytest cache, and Ruff cache directories.

Docker images, PostgreSQL data, and uploaded datasets used by Compose are stored in Docker-managed images/volumes. Temporary download caches and the Chromium browser used for verification live under `/private/tmp/forecastiq-*`.
